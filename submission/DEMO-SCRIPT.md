# Demo recording script — target 2 minutes 20 seconds

This is a recording plan, not evidence that a video exists. Record the actual local app. Use English narration, no music or borrowed footage. Keep the simulation notice visible. Do not show credentials or unrelated browser tabs.

| Time | On screen | Narration |
|---|---|---|
| 0:00–0:15 | App home, simulation notice | “Someone notices the kitchen sink is leaking. Usually that becomes a message, two quotes, and a repair nobody quite owns. Household Repair Desk keeps that loose end in one place. This is a local Alexa+ experience simulation.” |
| 0:15–0:35 | Type the leaking-sink report; compare | “Alex reports the leak. The task now has a saved record. We compare two fictional quotes, with their source documents available beside the prices.” |
| 0:35–0:58 | Open source quotes; return to cards | “Clear Pipe looks cheaper at 130 dollars, but parts are extra and unknown. Homekind costs 145 including the standard seal, with a longer warranty. We don't invent a final price to declare a winner.” |
| 0:58–1:18 | Choose Homekind, show unavailable morning, select afternoon | “A cheap appointment isn't useful if nobody is home. Monday morning is unavailable. The sample household calendar says Sam can supervise in the afternoon, and that also works for this provider.” |
| 1:18–1:42 | Review modal, select Sam, check consent and approve | “This creates a review request. It does not book anything. Sam reviews the provider, exact time and scope, then explicitly approves this household plan. There is no tool that lets the assistant skip that review.” |
| 1:42–1:58 | Reload, show persistent timeline | “Reloading keeps the record and its timeline. Approval means the household agreed. It does not mean a contractor was contacted or paid.” |
| 1:58–2:15 | Terminal: npm test output and MCP test name | “Behind the simulation is a real MCP service using the official SDK and Streamable HTTP. Tests call it over HTTP and check conflicts, stale changes, cancellation, expired reviews and persistence.” |
| 2:15–2:20 | Return to approved plan | “One repair, visible tradeoffs, and a clear boundary between planning and acting.” |

Before recording, use a fresh local demo data file or a new task. Do not imply that guided text is live AI. No actual Alexa device or external provider is part of this demo. Keep the final edit strictly below 3:00, then seek publication authorization before uploading.
