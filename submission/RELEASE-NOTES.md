Household Repair Desk turns a fictional leaking kitchen sink into a household-reviewed repair plan, with quote exclusions and calendar conflicts visible throughout.

This release includes the runnable Node.js app, a real official-SDK MCP service using Streamable HTTP, tests, setup instructions, English judging materials, and a 140.8-second 1080p video of the actual interface with English narration and captions.

Download the MP4 to preview the full report → compare → source quote → calendar → review → reload → cancel flow. Narration is synthetic using Microsoft David Desktop. No generated product UI, music, live Alexa connection, live model, contractor booking, or payment is claimed.

The source archive excludes dependencies, runtime household data, local browser jobs and raw recording/audio files. Install with npm ci, then npm start. Node.js 22+ is required.

The GitHub-hosted MP4 is a review copy. A qualifying public YouTube/Vimeo upload and final Devpost submission remain separate steps; neither is represented by this release.
